## ۱. آماده‌سازی صبح روز دمو

روی همان میزبانی که دمو از آن پخش می‌شود:

```bash
make setup                                   # فقط اگر .venv وجود ندارد
make seed                                    # پایگاه‌داده را پاک و دوباره seed می‌کند
.venv/bin/python -m app.sample_sales         # var/sales-sample.xlsx را می‌سازد
make run                                     # http://0.0.0.0:8000
curl -s localhost:8000/health                # باید "status":"ok" و "demo_data":true بدهد
```

چک‌لیست:

- [ ] `make seed` **همان روز** اجرا شده است. دوره رقابت نمونه از «لحظه seed منهای ۷ روز» تا «به‌علاوه ۷ روز» است؛
      با seed قدیمی‌تر از یک هفته، صفحه رقابت بی‌صدا به «رتبه‌بندی / مجموع امتیاز ثبت‌شده» برمی‌گردد.
- [ ] فایل `sales-sample.xlsx` روی **دستگاهی که مرورگر دارد** موجود است؛ یا از لینک «دانلود sales-sample.xlsx»
      در `/admin/sales/new` استفاده کنید (فقط مدیر).
- [ ] یک تصویر JPG / PNG / WEBP کوچک‌تر از ۴ مگابایت روی همان دستگاه آماده است.
- [ ] بین `make seed` و شروع دمو هیچ‌کس با برنامه کار نکرده است (عددهای این سند از وضعیت تازه حساب شده‌اند).
- [ ] اگر چند نفر هم‌زمان وارد می‌شوند: محدودیت ورود ۱۰ بار در دقیقه برای هر نشانی است و پشت یک پراکسی ممکن است
      همه یک نشانی دیده شوند. در آن صورت: `KILOOS_LOGIN_RATE_LIMIT=100 make run`.
- [ ] `KILOOS_SECRET` در طول دمو ثابت می‌ماند؛ تغییر آن همه نشست‌ها را باطل می‌کند.

## ۴. بخش اختیاری — اصلاح امتیاز (نگار)

فقط اگر وقت هست. از همین نسخه، فرم اصلاح داخل پنل در دسترس است:

1. ورود با «نگار تهرانی» ← «صف بررسی» ← زبانه «تأییدشده» ← «بررسی» روی ارسال سارا.
2. در کارت «اصلاح امتیاز»، «دلیل اصلاح (الزامی)» را بنویسید و «ثبت اصلاح امتیاز» را بزنید.
   برای امتیاز فروش: «ورود فروش» ← جزئیات import ← کارت «اصلاح امتیاز فروش».

آنچه دیده می‌شود: «این امتیاز اصلاح شده است» با دلیل و امتیاز اصلاحی −۱۰. سپس با «سارا محمدی»: موجودی ۵، رتبه ۳،
و در «تاریخچه امتیاز» یک رکورد «اصلاح» با دلیل. رتبه‌بندی: امیر ۱۷ · مریم ۸ · سارا ۵.

نکته برای گفتن: چیزی حذف یا ویرایش نمی‌شود؛ اصلاح یک رخداد منفی جدید است و هر رخداد فقط یک‌بار قابل اصلاح است (D-004).
