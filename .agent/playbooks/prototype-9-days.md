# پلی‌بوک — ۹ روز تا Prototype (MS-01)

**امروز:** ۱۸ آبان ۱۴۰۵ / 2026-11-09
**MS-01:** چهارشنبه ۲۷ آبان ۱۴۰۵ / 2026-11-18
**MS-02 (بازخورد):** ۳۰ آبان ۱۴۰۵ / 2026-11-21
**حالت:** `MODE: P`

هدف این پلی‌بوک: تحویل یک **جریان end-to-end قابل اجرا** که بدون توسعه‌دهنده نمایش داده شود. نه بیشتر.

---

## اصل حاکم

> اگر قابلیتی مسیر دمو را تقویت نمی‌کند، در این ۹ روز ساخته نمی‌شود.

مسیر دمو (۹ حلقه):

```
ورود → لیست مأموریت → جزئیات → ثبت شواهد تصویری → وضعیت «در انتظار بررسی»
→ تأیید/رد اپراتور → Score Event → موجودی/تاریخچه امتیاز → رتبه‌بندی → ویرایش مأموریت توسط مدیر
```

مدیر می‌تواند مأموریت را ویرایش کند و اثرش دیده شود (حلقه ۱۰ در دمو).

| ID | فرض | چرا قابل بازگشت است |

| A-P4 | تأیید دستی توسط اپراتور؛ auto-approve خاموش | با OD-06 روشن/خاموش می‌شود (config) |

| A-P8 | کیف امتیاز غیرقابل مصرف (نمایشی) | OD-08؛ هیچ تعهد مالی ایجاد نمی‌کند |

- **خروجی روز:** پروژه بالا می‌آید، migration اجرا می‌شود، `/health` پاسخ می‌دهد.

### روز ۲ — ۱۹ آبان: ورود + پوسته اپ

### روز ۳ — ۲۰ آبان: مأموریت‌ها (خواندن)

### روز ۴ — ۲۱ آبان: ثبت submission + شواهد

## سناریوی دمو (۷ دقیقه)

| زمان | چه کسی | چه اتفاقی |
|---|---|---|
| ۰:۰۰ | ویزیتور | ورود (OTP/دمو) → خانه: امتیاز، مأموریت‌های امروز |
| ۰:۴۵ | ویزیتور | باز کردن «ثبت تصویر یخچال» → شرایط → آپلود عکس → ارسال |
| ۱:۴۵ | ویزیتور | وضعیت «در انتظار بررسی» + توضیح شفاف |
| ۲:۱۵ | اپراتور | صف بررسی → دیدن شواهد → تأیید |
| ۳:۰۰ | ویزیتور | اعلان/بروزرسانی: ۱۰ امتیاز — «چرا؟» → قانون و مأموریت |
| ۳:۴۵ | ویزیتور | امتیازهای من: موجودی + تاریخچه |
| ۴:۱۵ | ویزیتور | رقابت: رتبه من، رتبه‌بندی، tie-breaker |
| ۵:۰۰ | ادمین | ویرایش مأموریت: امتیاز ۱۰ → ۱۵، انتشار نسخه جدید |
| ۵:۴۵ | ویزیتور | مأموریت جدید → ۱۵ امتیاز؛ امتیاز قبلی دست‌نخورده |
| ۶:۳۰ | ادمین | import فایل فروش نمونه → خطاهای گزارش‌شده → امتیاز فروش |

**جمله بستن دمو:** «هر عدد قابل توضیح است، هر تغییر قابل ردیابی، و هر داده غیرواقعی برچسب دارد.»

## fallbackها (اگر عقب افتادی)

| ریسک | fallback |
|---|---|
| آپلود تصویر پیچیده شد | ذخیره فایل محلی + لینک داخلی؛ برچسب «ذخیره‌سازی موقت» |
| OTP/SMS آماده نیست | انتخاب کاربر دمو از لیست؛ `A-P1` |
| import فروش نرسید | فایل نمونه با ۱۰ ردیف + ۲ ردیف خطا (برچسب Sample) |
| leaderboard زمان‌بر شد | محاسبه on-read برای دوره کوچک؛ snapshot بعداً |
| پنل عقب است | فقط دو صفحه: صف بررسی + ویرایش مأموریت |

**fallback ممنوع:** جعل منطق کسب‌وکار، حذف idempotency، نمایش امتیاز بدون منبع، مخلوط‌کردن داده Demo با واقعی.
